# Fase 1 (análisis del videojuego)
Los jugadores están atrapados en una antigua escuela abandonada donde ay situaciones sobrenaturales, donde tiene que recorrer diferentes salones, resolver preguntas y acertijos de distintas materias como, matemáticas, inglés y cultura general, deberán encontrar llaves y evitar que el fantasma (él profesor) los atrape, por cada respuesta incorrecta el fantasma se acercara o también si se les acaba el tiempo en cada pregunta y si responden correctamente avanzaran más hacia la salida.
# Fase 2 (Diagrama de flujo)
En esta fase se realizo un diagrama de flujo de como seria el paso a paso para nuestro programa de video juego donde se podra elegir el menu que este le indicara dos opciones que puedan jugar dos personas o si unicamente quieren jugar de un solo jugador, al presionar una de estas opciones se establecera la partida del viedojuego y es donde se comenzara a ejecutar los niveles. 
# Fase 3 (Código del videojuego)
En esta fase se realizó el código del juego La Escuela Maldita, tomando como guía el diagrama de flujo. Primero se creó la opción para que el usuario elija entre 1 jugador o 2 vs 2 y pueda ingresar su nombre o el nombre de su equipo, en el código se utilizó input() para ingresar datos y print() para mostrar información. También se utilizó if, elif y else para tomar decisiones, for para repetir los niveles y def para crear la función principal del juego. Se agregaron vidas, puntos y llaves para controlar el progreso del jugador y por último, el programa muestra los puntos obtenidos y determina el ganador en el modo 2 vs 2.
